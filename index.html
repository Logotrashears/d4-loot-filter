Features

Built for the grind, tuned for the loot

Everything you need to turn a screen full of yellow and orange text into a readable, filterable feed of upgrades.

🧩

Regex affix rules

Match affix names with full regex — combine prefixes, suffixes, and implicit lines to catch exactly the rolls you care about.

🎯

Per-slot stat thresholds

Set minimum values for each gear slot, like 15%+ Critical Strike Damage on gloves or 800+ Item Power on weapons.

🚫

Auto-hide junk drops

Instantly suppress white, blue, and low-roll rare drops so only potential upgrades and legendary affixes stay visible.

👁️

In-game overlay preview

See how each rule affects drops before you commit — the overlay previews highlighted and hidden items in real time.

📦

Import / export rule sets

Share your filter with friends or grab community builds. Rule sets export as clean JSON and import in one click.
